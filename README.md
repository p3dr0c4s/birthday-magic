# Birthday Magic

Uma pequena surpresa de aniversário feita com HTML, CSS e JavaScript.

A ideia foi criar uma página simples e divertida para transformar um "feliz aniversário" em uma pequena experiência.

## O que tem

- Tela inicial com uma surpresa
- Balões e decoração em tons pastéis
- Personagem animado
- Bolo com vela
- Interação para apagar a vela
- Confetes
- Mensagem final
- Uma surpresa escondida no final
- Layout adaptado para celular

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

Baixe ou clone o repositório e abra o `index.html` no navegador.
## Sobre

Projeto feito para praticar HTML, CSS e JavaScript e, principalmente, fazer algo diferente dos projetos tradicionais.

Foi feito para ser simples, bonito e fácil de personalizar para qualquer aniversário.
